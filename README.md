# PromptVault - AI Prompt Manager Chrome Extension

Save, organize, search and reuse your best prompts for ChatGPT, Claude, Gemini, Perplexity and more.

## Features
- Save prompts with titles and tags
- Full-text search
- One-click copy
- Floating "Save to Vault" button on AI sites (select text first)
- Freemium model: 10 free prompts, unlimited on Pro
- Local storage (privacy-first, data stays on your device)

## Installation (Developer Mode)
1. Download or clone this repo
2. Go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select this folder
5. Pin the extension

## Deployment to Chrome Web Store
1. Zip the folder (exclude .git)
2. Upload to Chrome Web Store Developer Dashboard
3. Set up privacy policy (data is local only)
4. Add payment integration
